## 검증과 남은 문제
- API35 에뮬레이터에서 실제 분 입력, 1분 추가 사용, 쿨타임 만료와 기본 한도 복귀를 확인했다. 실물 Galaxy와 TalkBack 음성 검증은 수행할 수 없다.
- 기존 스크립트의 최초 홈 실행 뒤 백업 범위를 그대로 기록한다. settings-run2 이후에는 앱 실행/설치 전에 앱 데이터와 기기 설정을 백업하고 복원 해시를 비교한다.
- 글로벌 기록 절차가 갱신되어 이전 작업을 abort하고 원래 기준 해시를 상속하여 resumed Task-ID로 재등록했다. 구현과 과거 증거는 유지한다.
- `testDebugUnitTest` 48개 실패 0개, `assembleRelease` 성공, `lintDebug` 오류 0개/경고 25개. `apksigner verify --print-certs` 통과, 기존 서명 인증서 유지. 외부 게시와 push는 하지 않는다.
- 재현: JDK 17의 `JAVA_HOME`을 설정하고 `./gradlew.bat testDebugUnitTest assembleRelease lintDebug --console=plain`을 실행한다. API35 에뮬레이터에서 `python scripts/04_cycle_review.py --suite <home|settings|overlay|design|layout|details|permissions> --output outputs/v5.1/validation/<새 실행 폴더>`를 사용한다. 보존한 결과의 무결성과 APK 포장은 `--suite summary --output outputs/v5.1/validation/summary`로 검증한다.
- 정확한 커밋 메시지: `fix: 주기 연장을 분 단위로 지원하고 관련 동작 검증`. 사용자 소유 `.gitignore`/`.ignore` 변경과 로컬 도구 상태는 커밋에서 제외한다. APK는 기존 `*.apk` 규칙에 따라 Git 추적에서 제외하고 로컬 파일로 전달한다.
