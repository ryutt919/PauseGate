## v5.1
- **R1, 입력과 저장 단위**: 독립 읽기 전용 조사에서 정수 시간으로 고정된 picker/repository와 두 호출자를 확인했다. 총 분을 전달하고 기존 ms 저장 키를 유지했다. 48개 단위 테스트와 홈/개입 실제 입력으로 해결을 확인했다. [구현과 결과](01_계획_구현_결과.md).
- **R2, 추가 앱 결함 여부**: 저장소/정책/호출자 검토에서 별도의 확정 결함을 발견하지 못했다. 연장 시 일반 대기가 다시 시작되는 기존 동작은 유지한다. 이는 총 한도를 늘리는 기능이며, 이미 쓴 시간을 초기화하거나 일반 대기를 우회하지 않는다.
- **R3, 테스트의 약한 판정**: 독립 검토에서 사용 스위치 검사와 달력 탭 검사가 화면 문자열만으로 통과할 수 있음을 지적했다. 실제 새 개입 유무와 달력 본문으로 보강한 [설정 검사](../outputs/v5.1/validation/settings-run2/00_runtime.json)가 통과했다.
- **R4, 복원 범위**: 초기 실행은 최초 홈 실행 뒤의 파일을 백업했다. 이 한계를 소급해 숨기지 않았다. 이후 실행은 앱 실행/설치 전에 백업하고 마지막에 파일 SHA-256과 기기 설정을 비교한다. [매니페스트](../outputs/v5.1/validation/summary/manifest.json)에 실행별 백업 시점을 기록했다.
- **R5, UI 자동화 오류**: 가로 화면의 스크롤/키보드/포커스, 커스텀 달력의 일반 View 노출, API35의 topResumedActivity와 배터리 설정 리디렉션을 화면과 dumpsys로 확인했다. 도구 판정만 수정했으며 [가로](../outputs/v5.1/validation/layout-run2/00_runtime.json)와 [권한](../outputs/v5.1/validation/permissions-run2/00_runtime.json) 재검증이 통과했다. 과거 실패 기록은 보존했다.
- **R6, 검토 한계**: API35 에뮬레이터 기능 검사 23개와 여섯 테마 화면을 직접 확인했다. 실물 Galaxy/TalkBack 음성은 미검증이고 lint 경고 25개가 남는다. 사용자에게 미확인 결과를 완료로 제시하지 않는다.
