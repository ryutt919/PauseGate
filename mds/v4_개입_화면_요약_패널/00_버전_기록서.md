- **사용 모델**: claude-sonnet-5-5
- **사용자 요구사항**: 앱을 지연하는 개입 화면에 쿨타임 시간, 오늘 해당 앱 사용 시간과 통계를 너무 크지 않게 적당한 사이즈와 위치에 보여주기. 서브에이전트로 구현과 테스트 후 릴리스까지.
- **버전**: v4 (폴더 v4_개입_화면_요약_패널), 앱 0.8.0 / versionCode 9.

## 개요
- 개입 화면 문구 아래 가운데에 작은 요약 패널을 두고 쿨타임 남은 시간, 오늘 해당 앱 사용 시간, 이 앱의 오늘 통계를 보여준다.
- 채택 상태: 현역. [0.8.0 릴리스](https://github.com/ryutt919/PauseGate/releases/tag/v0.8.0)를 게시했다.

## 직전 버전과 달라진 점
- v3 앱 0.7.0은 쿨타임 중에만 라벨 아래에 16sp 한 줄로 남은 시간을 보였고 사용 시간과 통계는 개입 화면에 없었다.
- v4 앱 0.8.0은 쿨타임 줄을 패널로 옮기고 사용 시간과 통계 행을 더했다. 패널은 13sp, 최대 280dp, 문구 34sp보다 훨씬 작다.
- 정책, 저장 키, 패키지, 서명, 통계 집계는 바꾸지 않았다.

## 요구 해석
- 사용자가 두 문장으로 나눠 말한 요청을 한 요청으로 확인했다("크기와 위치" 요구와 "쿨타임 시간, 오늘 사용 시간과 통계" 요구).
- "통계"는 이 앱의 오늘 개입 횟수, 참음 횟수와 비율로 해석했다. 7일 추이나 연속 일수는 넣지 않았다.

## 방법론
- 패널 행(해당 데이터가 있을 때만): 쿨타임 남은 시간(쿨타임 중, 매초 갱신), "오늘 {앱} 사용 N시간 M분", "이 앱 오늘 개입 N회, 참음 M회 (P%)".
- 사용 시간은 기존 Util.usedTodayMs 값을 쓰고 사용 정보 접근 권한이 없으면 null로 전달해 행을 숨긴다(0분으로 거짓 표시하지 않음).
- 통계는 StatsDb.appSeries의 오늘 값이며 참음은 DayStat.resisted(열지 않은 개입)로 홈과 통계 화면과 같은 정의다. 현재 개입은 begin 전이라 포함하지 않는다.
- 문구 생성은 Android 비의존 순수 함수(OverlayInfoFormat)로 두고 단위 테스트한다.
