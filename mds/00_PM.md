### 0.4.0 통계 고도화 (시안 A, B, C 중 B와 C 선택)
- [x] **이벤트 기록 구조**: 개입 1건을 SQLite `events` 한 줄로 저장(시각, 앱, 결과, 대기 시간, 한도 초과 여부). 일별, 앱별, 시간대별 값은 모두 이 기록에서 계산 — `StatsDb.kt`

  - 앱별 하루 사용 시간은 `daily_usage`에 쌓음. 시스템 기록이 짧아서 앱이 따로 보관(최근 7일 소급)
  - 0.3.1 이전의 날짜별 합계는 `legacy_daily`로 이전(앱 정보 없음, 요약과 달력에는 포함, 앱 목록에서는 제외)
- [x] **앱별 탭(B안)**: 오늘, 7일, 30일, 전체 기간 선택. 참은 비율 요약, 앱별 목록(사용 시간, 한도 진행 바, 개입과 참음 횟수), 앱을 누르면 최근 7일 막대 — `StatsActivity.kt`, `StatsViews.kt`
- [x] **달력 탭(C안)**: 연속 일수(참은 비율 60% 이상인 날), 월 달력(참은 비율이 높을수록 진하게), 날짜를 누르면 앱별 내용과 시간대별 개입 — `StatsActivity.kt`, `StatsViews.kt`
- [x] **메인 화면 연결**: 통계 요약 두 줄과 "통계 자세히 보기" 버튼. 옛 오늘 사용 시간 목록은 앱별 탭의 "오늘"로 이동
