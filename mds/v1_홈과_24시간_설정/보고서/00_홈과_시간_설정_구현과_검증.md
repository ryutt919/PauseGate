## 결과와 변경
- 첫 화면을 홈으로 전환하고 오늘 개입, 참음, 그래도 열기, 참은 비율과 활성 상태를 표시한다.
- 통계와 설정을 홈 버튼으로 열고 시스템 뒤로 가기로 돌아온다.
- 통계와 같은 Prefs 테마 6종을 사용한다. 기존 메탈 그라데이션과 라벤더 색은 사용자 지정 테마이므로 보존한다.
- 기존 설정을 SettingsActivity로 옮기고 시/분/초 직접 입력 창을 공용으로 사용한다.
- 일반 대기: 3초~24시간. 한도 초과 대기와 다시 묻지 않기: 1초~24시간.
- 한도 초과 대기는 일반 대기의 배수 계산에서 독립 설정으로 변경하고 새 기본값은 요청에 맞춰 30초로 둔다.
- 한도 초과 시간은 일반 시간을 대신한다. 앱별 하루 사용 한도 자체는 기존 설정을 유지한다.
- 기존 delaySec와 graceMin 값을 보존하고 graceMin은 graceSec로 최초 접근 시 변환한다.
- 앱별 유예 만료는 저장되어 서비스 재시작 후 유지된다.
- 대기는 elapsedRealtime 마감 시각으로 계산하여 절전이나 늦은 콜백에 영향받지 않는다.
- 1시간 이상 버튼은 HH:MM:SS로 짧게 표시하고 접근성 설명에는 전체 시/분/초를 유지한다.
- 24:00:01, 빈 입력, 최소 미만, 매우 큰 정수는 저장되지 않으며 취소 시 기존 값을 유지한다.
- 테마 선택 시 화면 재생성 대신 배경과 내용을 갱신하고 스크롤 위치를 복원한다.

## 구조와 적용 기준
- 실제 앱은 Kotlin 플랫폼 View이다. 요청한 Flutter 스킬의 화면과 저장/로직 분리 원칙을 기존 구조에 맞춰 적용했다.
- design-taste-frontend는 앱 화면을 기본 적용 대상에서 제외하므로 웹용 방향 추첨과 DOM 검사기는 적용하지 않았다. 기존 테마와 간결한 글자 계층, 단색 면을 유지했다.
- 앱 접근성과 탐색 검토에는 ui-ux-pro-max, 변경 범위 검토에는 karpathy-guidelines를 사용했다.
- 메인: 홈, 설정, 시간 입력 UI, 문서와 릴리스. medium 추론 서브에이전트: 시간 정책/호환성 구현, 독립 검토와 실행 검증.
