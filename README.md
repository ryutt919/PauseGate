# You sure?

지정한 앱을 열기 직전에 잠깐 멈추고 숨을 고르게 하는 안드로이드 앱입니다. one sec의 무료 버전 제한(앱 1개)이 없고, 설치된 모든 앱을 대상으로 고를 수 있습니다.

## 기능
- 대상 앱을 열면 숨쉬기 화면이 덮이고, 정해진 시간이 지나야 "그래도 열기"가 활성화됩니다.
- 설치된 모든 앱 선택(선택한 앱은 항상 맨 위), 검색, 전체 선택 / 해제
- 앱별 이용 한도를 모두 쓰면 쿨타임 중 대기 시간을 적용하고, 쿨타임이 끝나면 같은 한도를 다시 부여
- 개입 화면 문구 아래에 작은 요약 패널: 쿨타임 중이면 남은 시간(매초 감소), 오늘 해당 앱 사용 시간, 이 앱의 오늘 개입과 참음 통계. 사용 정보 접근 권한이 없으면 사용 시간 행을 숨김
- 홈에서 오늘 통계와 주기별 남은 이용 시간, 쿨타임 남은 시간을 매초 갱신해 확인
- 통계: 개입 기록을 앱 안에 쌓아서 앱별 목록(기간 선택, 사용 시간, 참은 비율, 앱별 7일 추이)과 달력(날짜별 참은 비율, 연속 일수, 시간대별 개입)으로 확인
- 색 조합 6종(메탈 회색 포함), 문구, 대기 시간, 숨쉬기 연출(아래에서 차올라 글자와 버튼까지 덮는 물결과 "호흡하세요") 켜기 / 끄기, 미리보기, 가로 화면 지원

## 빌드
필요한 것: JDK 17, Android SDK (platform 34, build-tools 34.0.0). Gradle은 wrapper가 내려받습니다.

프로젝트 루트에 `local.properties`를 만들고 SDK 경로를 적습니다. Windows에서도 슬래시를 쓰세요. 역슬래시는 이스케이프로 깨져서 빌드가 실패합니다.

```
sdk.dir=C:/Users/내이름/AndroidProjects/_tools/sdk
```

```bash
./gradlew assembleRelease
```

결과 APK: `app/build/outputs/apk/release/app-release.apk` (디버그 키로 서명되어 바로 설치할 수 있습니다)

## 설치 후 설정
1. 앱을 열고 접근성 서비스를 켭니다.
2. 일일 사용 통계와 서비스 재연결 시 앱 감지를 위해 사용 정보 접근을 허용합니다.
3. 배터리 최적화에서 이 앱을 제외합니다. 제조사가 서비스를 끄는 것을 막아 줍니다.
4. 앱 선택에서 대상 앱과 주기당 이용 한도를 고릅니다.
5. 설정에서 평소 대기 시간, 쿨타임 중 대기 시간, 쿨타임 기간을 각각 정합니다. 최대 24시간까지 설정할 수 있습니다.

한도 30분, 쿨타임 1시간, 평소 대기 7초, 쿨타임 대기 30초라면 한도 소진 후 1시간 동안 개입 화면에서30초를 기다려 앱을 열 수 있습니다.1시간 뒤에는 한도 30분이 다시 주어집니다. "다시 묻지 않기" 설정은 유지하되 한도 소진 직후 첫 쿨타임 개입은 이전 유예보다 우선합니다. 기존 멈칫의 설정과 통계는 덮어 설치하면 유지됩니다.

## 알려진 한계
- Google Play 배포는 접근성 서비스 심사 때문에 어렵습니다. 직접 설치용입니다.
- 앱 전환 직후 개입 화면이 한 박자 늦게 뜰 수 있습니다.

- 접근성 서비스가 꺼져 있던 동안의 사용량은 한도에 적립하지 않습니다.
- 일일 사용 통계와 주기당 한도는 별개이며, 일별 통계를 삭제하지 않습니다.
