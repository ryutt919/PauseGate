## Component Status

### GateService (접근성 서비스)
- **Current value/logic**: 창 전환 이벤트의 패키지 이름만 본다. 대상 앱이고 주기 한도가 소진되면 쿨타임 기간을 시작하고 별도 대기 시간을 적용한다. 한도가 남아 있고 일반 유예 시간이 아니면 일반 개입을 띄운다. 다른 앱으로 넘어가면 오버레이를 치운다. 앱별 유예 만료를 SharedPreferences에 실제 시각으로 저장해 서비스 재시작 후에도 유지한다.
- **Implementation**: `TYPE_ACCESSIBILITY_OVERLAY` 창. 닫기는 홈으로 보낸 뒤 1.5초간 같은 앱 재개입을 막는다.
- **Related files**: `GateService.kt`, `res/xml/accessibility_service_config.xml`
- **Rationale**: 접근성 오버레이는 별도의 "다른 앱 위에 표시" 권한이 필요 없다.

### OverlayView (개입 화면)
- **Current value/logic**: 맨 위에 닫기(강조)와 열기(윤곽선, "N초 후 열기"가 끝나면 "그래도 열기")가 가로로 나란히 있다. 버튼의 터치 영역은 52dp이고, 보이는 모양은 `InsetDrawable`로 사방 2dp 안쪽에 그린다. 열기 버튼의 흐림은 뷰 alpha가 아니라 글자 색 투명도로 낸다(가장자리 잘림 방지). 가운데에 앱 이름과 사용자 문구(34sp, 가로 28sp), 그 아래에 안내 문구 "호흡하세요"(24sp 굵게). 불투명한 물결이 아래에서 4초 차오르고 4초 내려가며 글자와 버튼을 덮는다. OverlayView는 평소에는 delaySec, 쿨타임 기간 중에는 limitDelaySec를 대기 시간으로 사용한다. cooldownSec는 별도 기간 설정이다. 일반 대기는 3초~24시간. elapsedRealtime으로 마감 시각을 계산한다. 1시간 이상 버튼은 HH:MM:SS로 표시하고 접근성 설명은 시/분/초 자연어를 유지한다.
- **Implementation**: 코드로 만든 View. `OverlayView`는 ScrollView(내용) 위에 `BreathView`(물결)를 마지막 자식으로 얹는다. `BreathView`는 터치를 받지 않아 아래 버튼이 눌린다. 안내 문구는 내용 쪽에 빈 slot View만 두고 `BreathView`가 그 위치에 직접 그린다. 물 경계를 기준으로 `clipOutPath`(물 위, 테마 글자색)와 `clipPath`(물속, 테마 bg색)로 두 번 그려 색이 뒤집힌다. 창 크기가 바뀌면(`onSizeChanged`) 세로, 가로용 크기로 다시 구성한다. 시스템 바와 노치 inset을 padding으로 반영한다. 뒤로 가기는 닫기와 같다.
- **Related files**: `OverlayView.kt`

### MainActivity / SettingsActivity (홈과 설정)
- **Current value/logic**: 런처는 홈이다. 멈칫 사용 스위치, 접근성/앱 선택 상태, 오늘 개입과 참음 비율, 통계와 설정 버튼, 현재 세 시간 요약을 표시한다.
- **Implementation**: ThemedActivity가 기존 테마 6종과 시스템 바, 버튼 스타일을 공유한다. SettingsActivity는 기존 권한/앱/동작/디자인 설정을 유지하고 세 시간을 공용 시/분/초 입력창으로 수정한다. 최소 미만과24시간 초과는 저장을 막고 취소 시 변경하지 않는다. 테마 변경 시 스크롤을 보존한다.
- **Related files**: MainActivity.kt, 12_SettingsActivity.kt, 13_ThemedActivity.kt, 14_DurationPicker.kt.

### AppPickerActivity (앱 선택)
- **Current value/logic**: 실행 가능한 모든 앱을 선택하고 선택된 앱은 검색 중에도 항상 맨 위에 표시한다. 앱별 주기당 한도0/1/15/30/60/90/120/180분을 고른다. 쿨타임 후 새 주기로 갱신한다.
- **Related files**: AppPickerActivity.kt.

### StatsDb / StatsActivity (통계)
- **Current value/logic**: 개입 1건 = `events` 한 줄. 결과는 PENDING, CLOSED, OPENED, DISMISSED. 참음은 열지 않은 개입(CLOSED + DISMISSED). 참은 비율 = 참음 / 개입. 연속 일수는 개입이 있었고 비율이 60% 이상인 날을 센다(오늘 기록이 없으면 어제부터). 앱별 하루 사용 시간은 `daily_usage`(앱이 시스템 기록을 가져와 최댓값으로 쌓음), 0.3.1 이전 합계는 `legacy_daily`.
- **Implementation**: `StatsDb`는 SQLiteOpenHelper(라이브러리 없음, 버전 1). `GateService`가 개입을 띄울 때 `begin`, 닫기와 열기에서 `finish`, 그 외로 화면이 사라지면 `DISMISSED`, 서비스 시작 때 `settlePending`. 첫 생성 때 설정 파일의 `stat_날짜_종류` 합계를 `legacy_daily`로 옮긴다(원본 키는 남김). `StatsActivity`는 앱 색 조합을 따르며 앱별 탭(기간 선택, 요약, 앱 목록, 앱별 7일 막대)과 달력 탭(연속 일수, 월 달력, 날짜 상세, 시간대 막대)으로 구성. 차트는 `StatsViews.kt`의 Canvas 뷰 3종.
- **Related files**: `StatsDb.kt`, `StatsActivity.kt`, `StatsViews.kt`, `GateService.kt`, `MainActivity.kt`
- **Rationale**: 합계만 저장하면 앱별, 시간대별 분석이 불가능해서 원본 이벤트를 남기고 집계는 조회 때 한다. 사용 시간은 시스템 기록 보관 기간이 짧아 따로 쌓는다.

### Prefs / Util (저장소와 도우미)
- **Current value/logic**: 테마 6종(숲, 밤바다, 노을, 라벤더, 종이, 메탈). 메탈은 `Theme.metal`이 true라 배경, 닫기 버튼, 물결에 금속 그라데이션을 쓴다. 기존 인덱스(0부터 4)는 그대로라 저장된 선택이 유지된다. SharedPreferences에는 설정과 앱별 유예 만료를 저장한다(통계는 StatsDb). graceMin은 최초 접근 때 초 단위 graceSec로 변환하며 기존 값은 보존한다. graceSec와 limitDelaySec는1초~24시간, delaySec는3초~24시간이다. 시간 정책과 표시를 11_DurationPolicy.kt에서 관리한다. 오늘 사용 시간은 UsageStatsManager로 조회한다.
- **Related files**: `Prefs.kt`, `Util.kt`
