### Animation
- **Current value/logic**: Each new intervention plays a four-second rise and four-second fall once, then stops both animators at level zero.
- **Implementation**: BreathView uses one reverse repeat and a started guard; GateService skips animation when reusing an intervention event.
- **Related files**: OverlayView.kt, GateService.kt.
- **Rationale**: Resizing and same-event cooldown/extension transitions must not restart the wave.

### Current-cycle quota
- **Current value/logic**: Choose hours and minutes for a total quota from 1 to 1440 minutes, strictly larger than the effective quota; preserve used time and the permanent default. The callback and repository API receive total minutes.
- **Implementation**: Immutable LimitCycleState.limitOverrideMs, pure LimitCyclePolicy.advance, and Repository persistence in cycle_limit_{package}; expiration clears the override.
- **Related files**: 15_LimitCyclePolicy.kt, 16_LimitCycleRepository.kt, Prefs.kt.
- **Rationale**: Keep extension policy and persistence outside UI rendering.
- **Cooldown behavior**: Extending during cooldown clears its deadline and resumes the remaining quota; it does not bypass the normal intervention wait.
- **Settings behavior**: Changing the permanent quota clears current usage, cooldown, and override; writing the same default preserves them.
- **Compatibility**: Existing `cycle_limit_{package}` values remain milliseconds. No migration or reset is performed for the minute-input update.
